# Wren's Letterboxd Sync

Obsidian plugin to sync Letterboxd RSS watches into one note per movie.

## Install

1. Build the plugin.
2. Copy `main.js`, `manifest.json`, and `styles.css` into `.obsidian/plugins/wrens-letterboxd-sync/`.
3. Enable the plugin in Obsidian.

## Use

1. Set your Letterboxd username in plugin settings.
2. Set the movies folder.
3. Run `Sync Letterboxd now` or wait for the timer.
